Cette page décrit les retours et échanges pour les commandes passées sur la vitrine Selfieface International (USD).

Éligibilité

Les produits non ouverts en état d’origine peuvent être éligibles dans un délai limité après livraison. Certains articles d’hygiène peuvent être exclus. Contactez le support avec votre numéro de commande.

Remboursements

Les remboursements approuvés sont effectués sur le moyen de paiement d’origine lorsque c’est possible. Les règles détaillées seront précisées dans une phase ultérieure.
